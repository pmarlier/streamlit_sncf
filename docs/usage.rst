Usage
============================
To run the app from the source code, simply type the following command:

.. code-block:: bash

    cd streamlit_sncf
    uv run streamlit run src/streamlit_sncf_app.py

Or launch the on-line version (hosted on StreamlitCloud) by reaching `https://meet-your-train.streamlit.app/ <https://meet-your-train.streamlit.app/>`_
